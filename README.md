# Basic Nvim

This is a basic Neovim config that contains only the necessary customizations to get you instantly productive. It is also a great starting point for creating your own Neovim config.

### How to use it

Clone the repository:

```bash
git clone git@github.com:DarrylDias/basic-nvim.git ~/.config/nvim

```

Then, run Neovim:

```bash
nvim

```

You can also read more about it [here](https://darryldias.me/blog/basic-neovim-config).
